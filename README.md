# Java Projects

Коллекция учебных проектов, разработанных в рамках обучения Java в **School 21**. Проекты охватывают основы объектно-ориентированного программирования, работу с коллекциями и Stream API, а также разработку веб-приложений с использованием Spring Boot.

---

## 1. Java Projects — основы Java и ООП

**Technologies:** `Java` · `OOP` · `Collections Framework` · `Stream API`

Учебные проекты, направленные на изучение основных принципов объектно-ориентированного программирования и обработки данных.

**Implemented:**
- Разработал иерархию классов с использованием наследования, инкапсуляции и полиморфизма.
- Реализовал интерфейсы и взаимодействие объектов различных типов.
- Использовал коллекции и Stream API для фильтрации, преобразования и обработки данных пользователей и объектов.

---

## 2. Tic-Tac-Toe — многослойное веб-приложение

**Technologies:** `Java 21` · `Spring Boot` · `Spring Web` · `Gradle` · `HTML` · `CSS` · `JavaScript`

Веб-приложение для игры в крестики-нолики с компьютерным противником, использующим алгоритм Minimax для выбора оптимальных ходов.

**Implemented:**
- Разработал REST API для создания и управления игровыми сессиями.
- Реализовал игровую логику, проверку ходов и алгоритм Minimax.
- Спроектировал многослойную архитектуру с разделением на `Web`, `Domain` и `DataSource`.
- Реализовал хранение игровых сессий в памяти с использованием `ConcurrentHashMap`.
- Разработал веб-интерфейс для взаимодействия с игрой.
